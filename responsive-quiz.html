🎯 Media Queries & Flexbox Quiz

Question 1: What does "Mobile First" mean?

Design for desktop first, then adapt for mobile
Design for mobile first, then enhance for larger screens
Only design for mobile devices
Use mobile apps instead of websites
Correct Answer: Mobile First means designing for mobile devices first, then progressively enhancing the experience for larger screens using media queries.

Question 2: What does this media query do?

@media (min-width: 768px) {
    .container { max-width: 750px; }
}
Applies styles when screen is smaller than 768px
Applies styles when screen is 768px or wider
Applies styles only on tablets
Applies styles when screen is exactly 768px
Correct Answer: min-width: 768px means the styles apply when the viewport width is 768 pixels or wider. This is the Mobile First approach.

Question 3: What does flex: 1 mean in Flexbox?

Makes the item fixed width
Makes the item hidden
Makes the item grow to fill available space
Makes the item centered
Correct Answer: flex: 1 is shorthand for flex-grow: 1; flex-shrink: 1; flex-basis: 0%. It makes the flex item grow to fill available space.

Question 4: Which Flexbox property aligns items vertically?

justify-content
align-items
flex-direction
flex-wrap
Correct Answer: align-items aligns flex items along the cross axis (vertically by default). justify-content aligns along the main axis (horizontally by default).

Question 5: What's the best breakpoint for tablets?

320px
768px
1024px
1440px
Correct Answer: 768px is the standard breakpoint for tablets. Common breakpoints: Mobile (<768px), Tablet (768px-1023px), Desktop (1024px+).

Question 6: What does flex-wrap: wrap do?

Makes items stack vertically
Makes items equal width
Allows items to wrap to next line
Makes items centered
Correct Answer: flex-wrap: wrap allows flex items to wrap onto multiple lines if they don't fit in the container's width.

Question 7: What is the viewport meta tag for?

To add animations
To change colors
To control how the webpage scales on mobile devices
To add JavaScript
Correct Answer: The viewport meta tag tells the browser how to control the page's dimensions and scaling on mobile devices. <meta name="viewport" content="width=device-width, initial-scale=1.0">

Question 8: Which unit is best for responsive typography?

px (pixels)
rem (root em)
pt (points)
cm (centimeters)
Correct Answer: rem is best for responsive typography because it's relative to the root font size and scales consistently across devices.
