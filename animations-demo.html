🎬 CSS Animations - @keyframes

🎯 Basic @keyframes

Fade In Animation

Opacity: 0 → 1

Keyframes:

@keyframes fadeIn {
    from { opacity: 0; }
    to { opacity: 1; }
}

🔄 Complex @keyframes

Slide In Animation

Multiple steps with opacity and position

Keyframes:

@keyframes slideInFromLeft {
    0% { opacity: 0; transform: translateX(-100px); }
    50% { opacity: 0.5; transform: translateX(-50px); }
    100% { opacity: 1; transform: translateX(0); }
}
